# Rom. v
Verilog ROM

 Project Description

ROM (Read Only Memory) is a memory device used to store fixed data. The stored data can be read using an address input. In this project, a simple 8 × 8 ROM is designed using Verilog HDL.

The ROM has:

- 3-bit address input
- 8 memory locations
- 8-bit data output

Specifications

Parameter| Value
Memory Size| 8 × 8
Address Width| 3 bits
Data Width| 8 bits
Language| Verilog HDL

Working

The 3-bit address selects one of the 8 memory locations. The corresponding 8-bit stored data appears at the output.

 Files

- "rom.v" – Verilog design code
- "rom_tb.v" – Testbench
- "simulation.txt" – Expected simulation output

 Applications

- Microprocessors
- Embedded systems
- Lookup tables
- Digital systems
- Memory-based circuits

Conclusion

This project demonstrates the design and simulation of an 8 × 8 ROM using Verilog HDL.
